Install uv package manager:
1.	Open terminal/powershell
2.	Paste and run this command: curl -LsSf https://astral.sh/uv/install.sh | sh if MacOS/Linux
3.	Paste and run this command: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex" if Windows OS
4.	Check installation : uv --version

Create virtual env:
1.	uv python install 3.9
2.	uv venv --python 3.9 .venv
3.	source .venv/bin/activate for mac/linux 
	.venv\Scripts\activate for windows
4.	uv pip install -r requirements.txt # requirements_macos.txt for Mac OS.
	normal pip install -r requirements.txt is showed some conflicts between numpy and opencv for me in windows, so I used uv pip
5. check if opencv is installed properly:
	python
	import cv2
	exit()
	if it throws any errors, run the below commands in linux terminal
	sudo apt update
	sudo apt install -y libgl1
